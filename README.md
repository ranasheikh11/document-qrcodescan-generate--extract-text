# 📄 Document Scanner & QR Toolkit (Flutter)

A powerful all-in-one Flutter application that allows users to scan documents, extract text using OCR, edit content, generate QR codes, and scan QR/Barcodes seamlessly.

---

## 🚀 Features

### 📷 Document Scanning

* Capture documents using camera or select from gallery
* Optional image cropping for better accuracy
* Clean and optimized scan output

### 🔍 Text Extraction (OCR)

* Extract text from images using advanced OCR technology
* Supports multi-line and structured text recognition
* Fast and accurate processing

### ✏️ Text Editing

* Edit extracted text easily inside the app
* Copy, update, and manage text content

### 🔳 QR Code Generator

* Convert any text into QR code instantly
* Generate QR codes for links, messages, or custom text
* Save and share generated QR codes

### 📡 QR & Barcode Scanner

* Scan all types of QR codes and barcodes
* Supports URLs, text, contact info, and more
* Fast real-time detection

### 💾 Save & Share

* Save scanned documents and QR codes locally
* Share content easily with other apps

---

## 🧰 Tech Stack

* **Flutter**
* **GetX** (State Management)
* OCR: Google ML Kit
* QR Generation: qr_flutter
* Scanner: mobile_scanner
